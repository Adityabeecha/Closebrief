Security and governance

Last updated 14 November 2026

Short answers to what a finance, IT or procurement review asks before real figures go in. Where something isn't in place, it says so.

How the numbers are made

  • Every KPI, variance and total is computed in code from your file. The AI never calculates a figure.
  • The AI only writes the words. Every number in a draft is checked against the computed figures; a draft with a number that doesn't match is marked, and it can only be approved with a written reason.
  • A dataset whose name says "thousands" or "millions" while its amounts are stored as entered can't be exported, shared or approved until someone confirms the units.

AI provider

ProviderOpenAI, through its API.
What's sentA KPI's computed figures, the notes that explain it, and any text you paste or question you ask. Your uploaded files aren't sent.
TrainingOpenAI doesn't train its models on API data. It keeps API data for up to 30 days for abuse monitoring.
Hiding namesWords you list (company, customers, people) are swapped for placeholders before anything is sent, and put back in the reply.

Where data lives

RegionUnited States.
Sub-processors Render: runs the app.
Supabase: the Postgres database and email sign-in.
Upstash: a Redis cache of drafted text, so the same request isn't paid for twice; entries expire on their own.
OpenAI: drafting, as above.
Google: only if you sign in with Google, or link a Google Sheet.
Sentry: crash reports, if error monitoring is switched on.
In transitHTTPS only, with HSTS.
RetentionUploaded files are deleted after 7 days; the figures stay with the dataset. Unused workspaces are deleted after 12 months. Full details are on the privacy page.

Access

  • Workspaces are separate. Every query is scoped to your workspace, and Postgres row-level security enforces it again in the database.
  • Roles: admins and analysts import, draft and approve; executives and viewers read. Admins set each person's role.
  • Approval by link: a manager can approve one close from a signed link without an account. It shows only that close's drafts and expires after 7 days.
  • Sign-in: email (through Supabase) or Google. Sessions last up to 12 hours.

Audit trail

  • Imports, syncs, drafts, approvals, unit confirmations, locks, exports, approval links and sends are logged with who, when and what. Every edit to a draft is kept as a version you can compare.
  • Each entry is chained to the one before it by a hash, so editing or removing an entry breaks the chain. Admins can re-check the whole chain from the Activity page.
  • The log is kept after a workspace is deleted, so the history can't quietly disappear.

Your data out

  • Download everything in a workspace as one file, or delete all of it in one step, from Settings → Workspace and data.
  • Each close also exports to Excel with its figures, commentary and change log.

Not in place yet

  • No SOC 2 or other independent audit. Closebrief is a small independent project.
  • No SAML SSO or SCIM. Sign-in is email or Google.
  • No signed DPA and no uptime guarantee (SLA).

The source code is public, so a reviewer can read exactly what happens to the data.
