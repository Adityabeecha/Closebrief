How Closebrief works

The core rule: the AI never computes numbers. Every value, delta, and trend is calculated deterministically; the model only writes the prose around pre-computed facts.

  1. Import any CSV/Excel export — columns are auto-detected, you confirm the mapping.
  2. Pick KPIs — the board shows exactly the metrics you choose, with correct red/green direction.
  3. Add context notes (pricing changes, campaigns) so narratives can explain the why.
  4. Generate — grounded commentary with source chips and a "numbers verified" badge; anything unverifiable is flagged, never hidden.
  5. Digest & export — top movers in CFO language, one-click PDF/PPTX.
